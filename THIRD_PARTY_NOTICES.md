## Font Awesome

No Font Awesome file is part of this repository. The icon names and code points in
`IconsFontAwesome6.h` refer to [Font Awesome Free](https://fontawesome.com) 6 by Fonticons, Inc.
POE1Fixer ships the Font Awesome 6 Solid font itself and gives it to every plugin, so a plugin
only writes an `ICON_FA_*` string. Font Awesome Free is licensed under the
[Font Awesome Free License](https://fontawesome.com/license/free): icons under CC BY 4.0, fonts
under the SIL OFL 1.1, code under MIT.
